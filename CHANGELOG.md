# Changelog

## 0.1.0 (2026-11-02)

First release of the separate Nintendo DS version.

- All five levels with the original compiled level scripts, cutscenes, script cameras, dialogue with voices and Fleuriefee.
- RedCat at full model quality; other models at their original sizes.
- Targeting of enemies, shootable buttons and crates, with marker and lock while firing.
- Web port sound choices, including door sounds on real door panels only.
- Enemy behaviour per type, three bosses, difficulty choice, effects, level overview and retry screen.
- Saving at save points on a flash card, or in melonDS with DLDI turned on.

**Not tested:** the targeting, sound, enemy, effect, menu and save work in this release was compiled but not run.
Frame rate figures in the README predate it. Not tried on real hardware or played through.
